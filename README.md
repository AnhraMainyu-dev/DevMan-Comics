# Блог комиксов xkcd

Скрипт предназначен для автоматической публикации комиксов за авторством xkcd в своём телеграмм канале.

### Как установить

Для публикации изображений в телеграм канале вам потребуется токен вашего бота в Телеграме, который вы можете получить во время создания бота, а также id вашего канала или группы.
Они должны быть указаны в файле окружения .env в виде:
```commandline
TG_BOT_TOKEN=
TG_CHANNEL_ID=
```

Python3 должен быть уже установлен. 
Затем используйте `pip` (или `pip3`, если есть конфликт с Python2) для установки зависимостей:
```
pip install -r requirements.txt
```

### Как использовать

Запустите скрипт командой:
```
python auto_publish_xkcd_comics.py
```
Скрипт будет публиковать случайный комикс от xkcd в телеграмм канал раз в 24 часа, начиная отсчёт от момент запуска
